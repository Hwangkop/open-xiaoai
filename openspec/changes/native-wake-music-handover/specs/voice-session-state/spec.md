# Spec Delta

## MODIFIED Requirements

### Requirement: 播报不打断音乐态

播报期间系统 MUST NOT 把设备的静默当作“音乐结束”；播报结束后 SHALL 恢复音乐播放（设备暂停则 resume，设备已空闲则重新拉起当前曲目）。接管原生唤醒而冻结设备播放器时，冻结状态 SHALL 由会话状态所有者持有；冻结期间的静默 MUST NOT 触发音乐结束或自动续播，解冻 MUST 由同一所有者执行。

#### Scenario: 播报期间不退出音乐态

- **WHEN** 音乐播放中触发一次 TTS 播报
- **THEN** 音乐态保持，音量不还原

#### Scenario: 播报结束恢复播放

- **WHEN** 播报结束且当前仍在音乐态
- **THEN** 音乐继续播放（必要的话重新拉起当前曲目）

#### Scenario: 冻结期间不判定音乐结束

- **WHEN** 接管原生唤醒期间设备播放器被冻结，且时长超过自动续播的判定窗口
- **THEN** 音乐态保持，不切歌，也不把静默记为播放结束

#### Scenario: 解冻由所有者执行

- **WHEN** 接管结束需要恢复设备播放器
- **THEN** 只有会话状态所有者发起解冻，并同步恢复音乐的播放状态
