# 把知识自然用进聊天（v11）

目标：在用户愿意一起解决眼前问题时，把可靠资料转成一个可尝试的方法；通过实际反馈帮助他逐渐掌握，保留闲聊、倾诉、休息和自己选择的空间。不把“潜移默化”变成每句说教，也不把一次采纳当成已经养成习惯。

## 对话策略

以下是供模型判断的路径，不是每轮必须照做的台词或流程。

| 对话信号 | 应有行为 | 避免 |
| --- | --- | --- |
| 想吐槽、休息、玩故事 | 自然陪聊，跟随当下话题 | 关键词触发查书、布置成长任务 |
| 愿意一起想怎么做 | 找一个实际卡点，按需检索并读原文 | 先讲整套理论、多本书拼成课程 |
| 想试一试 | 把相关方法转成一个低负担小动作，说明为何适合当前卡点 | 无期限地要求坚持、打卡或保证见效 |
| 主动反馈有进展 | 指出具体做法和变化，留下选择空间 | 空夸天赋、抢功、自动提高难度 |
| 主动反馈没效果 | 看实际反馈，愿意继续时只调整一处 | 归咎意志力、机械重复旧方法 |
| 拒绝建议或拒绝某方法 | 停止；在可见后续聊天中继续尊重这个边界 | 改个名称继续推送、换一道作业 |
| 问为什么、问来源 | 解释可迁移的一点；来源对应实际检索结果 | 编书中原话，隐瞒自己的改编 |
| 想自己练习 | 留一小步提示，等用户决定；要答案就回答 | 抢着代做，或反过来强迫考试 |

“卡住了，你陪我想想”也可以是方法求助，不要求用户必须说固定口令；仅一句“今天真忙”不等于同意接受指导。最多问一个必要的具体问题，不把聊天做成问卷。

## 知识怎样进入回答

沿用现有 `search_book → read_book_section`，通常读一两个片段。同一可见上下文中已经读到且仍适用的内容不重复检索。检索失败、内容不相关或条件不适合时，不硬套、不假装查过。

系统提示词保留可迁移的聊天原则，原始书籍仍在知识库按需读取；不将全书、全部章节摘要或临时用户历史拼进每轮提示词。

回答通常只取一点，用自己的口语解释，默认不报书名和方法名。用户追问就坦诚说明实际来源与章节；对原书方法的简化说成“这次可以先试……”，不能当成书中原始练习。针对儿童先考虑年龄、自主性和负担，不因资料有“学习”标签就照搬成人经验。

投资资料只在用户主动讨论相关问题时用于认知与风险说明，不将普通家庭开销或存钱话题自动引向投资，不荐标的、不保证收益。健康问题不拿书中个人经验当成通用依据。

## 多轮反馈与记忆边界

v11 实现的是**当前可见会话中的承接**：利用真实上下文里的目标、已试办法、用户反馈和拒绝来调整接话；没有新增用户画像、自动打卡或长期监督服务。

Codex thread 可以保留对话上下文，但重置、压缩或切换会话后，模型不一定还能看到相关信息。不能据此承诺永远记住、推断不同说话者是同一人，或把通用书籍知识当作个人历史。新会话缺背景时请用户补充，不编造上次的约定。需要定时提醒时走现有任务工具，执行成功才确认。

后续若建立长期学习记忆，单独设计为可查看、可改、可删除的个人记录，不混进参考书籍。建议只保存用户确认的目标、偏好、试过的方法及用户自述的反馈，并带原始依据和时间；不推断人格、心理诊断或隐私。家庭多成员身份尚不可靠时，不自动建立跨会话个人档案。

## 验收与限制

检查真实工具调用、方法与原文的一致性、拒绝后的连续行为、是否重复检索、是否虚构记忆，以及故事/倾诉是否被改造成课堂。正反场景都要覆盖，不能只检查“有没有出现书里的词”。

静默文字试验可以发现回答与工具使用的问题，不能证明已经改善真实生活习惯；多次实用反馈和实际听感仍是后续依据。部署提示词时只更新该字段并建立新主 thread，避免恢复旧 thread 后规则未生效；旧会话入口备份可恢复。

服务端 `chat.log` 另有识别文本、生成的播报句子、耗时和错误记录；生成文本不证明音箱已完整播放。当前管理台只提供会话状态、轮数、重置和压缩，没有完整聊天回放与反馈标记，也没有后台自动评审或自动训练。

用户正常聊天即可；工程侧打磨时读取真实记录，关联用户输入、回复、检索与业务工具结果，区分识别、检索、表达和执行问题，将可复现问题加入回归，再验证修改。无需让用户自己编写提示词或逐条打分。实际听感、误识别的原意等日志无法判断的内容，仍需结合用户自愿提供的反馈。

首次抽样发现两个旧版候选回归案例，尚不能据此断言当前 v11 仍然存在：

- 用户说“继续播放”，实际调用 `next_music`；验证应恢复当前曲目，不能把继续误当切歌。
- 用户问“今天会下雨吗”，该轮直接给出具体天气，抽样未见天气查询；回归需核对可见上下文中的来源与时效，无依据时不得编具体天气。

后续复查以真实问题是否减少为依据，同时保留好的接话样例；聊天记录持久化不等于模型能看到全部旧会话，也不等于已经建立跨会话个人成长记忆。
