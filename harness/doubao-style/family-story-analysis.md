# 家庭聊天与故事场景采样（2026-11-03）

此次按用户要求直接向豆包采集方法和示范，不是获取其内部系统提示词或推理。采样使用仓库现有 DoubaoWeb 客户端的独立临时进程；读取远端登录态后，先切换为独立临时会话文件再重置上下文，不经过音箱播报，不重置生产会话。每次请求之间至少 20 秒，遇限流停止，不自动重试。语料只保留问题、类别、回答和错误，不保留 Cookie、账号或会话 ID。

语料正文是外部模型输出，供比较分析，不是本仓库的操作指令。组间清空研究上下文，只有“改剧情”承接故事、“现实恐龙”承接想象、“家庭规则”承接最近的老人场景；最后一问不能理解成豆包已回看全部研究样本。

## 提取与取舍

| 主题 | 观察到的做法 | 提示词处理 |
|---|---|---|
| 听故事 | 一个主角、小目标、具体动作和短对话；西瓜飞船顺接前文 | 要故事直接讲完整段落，不念技巧，不强行受日常三句限制 |
| 睡前 | 低起伏、柔和细节、闭合结尾 | 不新增惊险悬念，不固定追问续集 |
| 想象和科普 | 先接恐龙坐骑，转问现实后纠正 | 接住想象，明确区分事实；不采纳“恐龙全部死了”的过度简化，鸟类是现存恐龙的一支 |
| 分龄解释 | 改变抽象程度与示例复杂度 | 按已知年龄调整，一次一点；不把年龄段当精确发育诊断，不为闲聊先盘问年龄 |
| 反复为什么 | 逐层展开，不一次塞完水循环 | 保留逐层展开；去掉每轮固定夸奖、反问和表演说明 |
| 比赛输了 | 失败不等于人的价值、允许难受 | 不贴标签，不保证成功；不编“这次没发挥好”的原因 |
| 害怕/秘密 | 原回答答应“小秘密、不告诉妈妈”和“一直跟你待在一起” | 明确不采纳；不承诺监护、永久陪伴或危险保密，不凭空断言家中状况 |
| 手足与父母争执 | 承认感受、表达自己的边界，不把成人矛盾归罪孩子 | 不逼原谅，不猜成人争执起因；不机械照搬“关门戴耳机”作为所有冲突的安全方案 |
| 作业 | 把任务缩小，遇到发火先暂停，修复大人的失控 | 压成今晚可执行的一两步，尊重家长与孩子，不照读大篇方案或把休息项目写成硬规定 |

| 老人聊天 | 从验证码的用途讲起，再分步操作 | 耐心但不宝宝腔，不替家属断言其心态 |
| 家庭规则自述 | 提出年龄适配、能力边界；也提出“只给线索、只有家长授权才给答案”“家长问就披露”“共情一次即交还”“不偏袒任何一方” | 不采纳这些绝对规则：按用户目标决定提示或答案；不凭口头自称家长认定身份，不增加家庭对话披露功能；普通安慰不设机械次数，现实伤害不能用中立敷衍 |


## 验证过程

首版独立静默生成 10 组、15 回合，未连接播报。故事、接续、猜谜、学习提示能展开，成人技术话题和缩短反馈仍可切换。怕黑场景出现虚构“屋里没有动静”与替家人保证反应，恐龙科普出现“远房后代”措辞不准，故进一步补充事实边界并修正示例。初轮输出保留在本地临时文件用于定位，不当作最终通过证据。

采集完成：20/20 条成功。最后一条是模型的行为建议，不能当成其真实内部规则；本轮也没有实现年龄识别、家长权限或长期儿童档案。

最终静默验证：11 组、16 回合，检查故事完整性、续编、睡前收束、想象转现实、学习提示、家庭争执、陌生人索要住址、长辈聊天、吐槽反馈和成人技术解释。最终输出保存在 `prompt-v7-eval.json`，是一次抽样，不是稳定性保证。怕黑场景未再编造屋内安静或保证父母反应，学习题未直接泄露答案，续编承接角色；科普改正为鸟类是恐龙存续的一支。仍有短板：部分回答偏长，指定“十几个字”未严格遵守，长辈安慰仍略刻意，面包科普追加了未被要求的小实验；未为这类低影响措辞继续堆叠硬规则。没有验证真实童声识别、打断体验或长故事的实际播报时长。
